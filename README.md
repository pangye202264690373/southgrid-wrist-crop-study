# Southgrid · Wrist crop study

Interactive visual comparison of four complete recordings, both wrist cameras, and five 224×224 processing methods. Data processing only; no model training or inference.

Open the GitHub Pages website associated with this repository. The synchronized video preview is compressed at CRF 22. Original CRF 12 224×224 downloads and lossless PNG keyframes are retained; use PNGs for fine-detail inspection.

The full source recording sequences are preserved in all videos. Existing acquisition gaps remain unchanged. See `manifest.json` and `validation.json` for processing and verification records.
